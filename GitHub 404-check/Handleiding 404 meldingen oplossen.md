## Zo los je een melding op

1. **Open de kolom `Bronpagina`**  
   Dit is de pagina waarop de niet-werkende link is gevonden. Zoek daar waar de link in de tekst staat.

2. **Bekijk de kolom `Gevonden URL`**  
   Dit is de link die momenteel een 404 geeft. Controleer wat de juiste nieuwe URL moet zijn.  
   Is de informatie niet meer beschikbaar of relevant? Verwijder de link dan.

3. **Zoek de link in de GitHub-repository**  
   Open de repository die in het overzicht staat en zoek op de exacte oude URL. Je kunt daarvoor de zoekfunctie van GitHub gebruiken.

   Bijvoorbeeld:

   ```text
   "https://oude-url.nl/pagina"
   ```

   Zo vind je snel het bestand waarin de link staat.

4. **Pas de link aan**  
   Open het gevonden bestand in GitHub en kies het potlood-icoon **Edit this file**.

   Vervang de oude link door de juiste nieuwe URL, of verwijder de link als de informatie niet meer relevant is.

   Sla de wijziging vervolgens op via een commit of Pull Request, afhankelijk van de werkwijze binnen de repository.

5. **Controleer na publicatie**  
   Open na het publiceren de betreffende GitHub Pages-pagina en controleer of de nieuwe link correct werkt.

## Ben je niet meer de eigenaar?

In de `README` van de repository staat aangegeven wie verantwoordelijk is.

Bijvoorbeeld:

```markdown
| Eigenaar | Ingevuld door |
| --- | --- |
| Kennis Centrum Architectuur | John Smit |
```

Ben jij niet meer de eigenaar? **Pas deze informatie dan direct aan naar de huidige eigenaar.**

Bij een volgende controle gebruiken we deze gegevens om het overzicht bij de juiste persoon terecht te laten komen.

## Ieder kwartaal een nieuwe controle

We voeren deze controle voortaan **ieder kwartaal** uit.

Daarmee willen we het eenvoudig maken om verouderde links tijdig op te sporen en samen de kwaliteit van onze GitHub Pages te verbeteren.

Het overzicht is daarmee meer dan een lijst met technische foutmeldingen. Het is een periodieke kwaliteitscontrole op de informatie die we publiceren.

Door 404-links tijdig te herstellen zorgen we ervoor dat:

- informatie betrouwbaar blijft;
- bezoekers snel bij de juiste informatie komen;
- verouderde verwijzingen worden opgeruimd;
- onze GitHub Pages actueel en bruikbaar blijven.

**Controleer daarom de meldingen die bij jouw repository horen en herstel ze waar mogelijk.**
